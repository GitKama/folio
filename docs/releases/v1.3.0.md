# Folio 1.3.0 — Copy for Microsoft Teams

Released 27 October 2026. Copy your current Markdown draft as formatted clipboard content for the Microsoft Teams composer.

## Use it

Choose **Export → Copy for Teams** (or **File → Copy for Teams**), then **Ctrl+V** into Teams. The export includes unsaved edits, without saving or sending anything. Document details lists conversion notes.

Common formatting stays rich: bold, italic, strikethrough, links, lists, headings, quotes and code. Tables become labeled rows; math and diagrams retain their source; folded callouts include their full body; local images become descriptive labels. The plain-text clipboard fallback remains readable. An 80 KB budget rejects oversized output without truncation.

See the [Teams guide](../teams-export.md), [synthetic example](../../samples/teams.md), and [changelog](../../CHANGELOG.md).

## Compatibility boundaries

This release targets the Teams message composer, not bot/card/webhook Markdown. Teams chooses the final appearance of headings and code. Math and diagram rendering, custom styles, embedded images, and table grids are not reproduced. See the guide for every fallback. Web/mobile clients, sent-message rendering and tenant-specific policies are not certified; this is not a universal 100% fidelity claim.

Windows x64 builds remain unsigned. The installer was built but was not installed into a normal user profile during testing. Native dialog answers and clipboard writes are substituted in automated suites; actual clipboard and Teams draft checks were performed separately. Existing HTML/PDF export and editing workflows remain available. There is no autosave or crash-recovery store.

## Update and roadmap

Close Folio, then run **Folio-1.3.0-Setup-x64.exe** and select the existing installation directory, or launch **Folio-1.3.0-win-x64.exe** for portable use. Documents remain ordinary Markdown files; no migration is required.

A future migration to Rust is planned separately in [ROADMAP.md](../../ROADMAP.md). Version 1.3 remains Electron; no migration date or replacement UI framework has been selected.
