# Folio 1.2.0 — Designed PDF exports

Released 23 September 2026. This minor feature release adds three PDF profiles without changing the Markdown editing workflow.

## Choose the page that fits

- **Technical** is the initial choice: clear blue headings, action cards and meeting section breaks.
- **Studio** uses quiet teal accents and the original table grid for everyday reports.
- **Editorial** uses serif body text and warm accents for longer reading.

The export dialog remembers the last profile and layout switches. Wide-table cards and meeting section layout can be adjusted separately. All profiles include A4 pages, page numbers, a running document name, selectable text and embedded supported images, math and diagrams. PDF typography stays light when the reader is dark. Exports include the latest unsaved edit without saving or rewriting the Markdown.

See the [PDF guide](../pdf-export.md), [fictional meeting example](../../samples/meeting.md) and [changelog](../../CHANGELOG.md).

## Update

Close Folio, then run **Folio-1.2.0-Setup-x64.exe** and select the existing installation directory. The application identifier and local settings location are unchanged. Portable users can close the previous version and launch **Folio-1.2.0-win-x64.exe**. Documents remain ordinary Markdown files; no document migration is required.

## Limits

Windows x64 only. Both executables remain unsigned; this release does not satisfy a managed-PC policy that requires an approved publisher signature. The installer was built and its version metadata checked, but was not installed into a normal Windows profile. Native dialog answers are substituted during automated tests; real renderer, IPC, printing and filesystem behavior run.

Meeting section recognition currently uses English labels. Complex spanning/nested tables retain their grid. Very wide grids may need card mode; oversized cards can continue onto another page. Chromium PDF tags and outlines are enabled, but PDF/UA conformance is not certified. Already-rendered diagrams preserve their own light/dark theme. There is no autosave or crash-recovery store.
