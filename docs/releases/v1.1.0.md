# Folio 1.1.0 — Markdown editing

Public release prepared on 21 September 2026. This release adds editing to the existing Source and Split views while retaining the reader and export features.

## Included

Live preview while typing; native undo/redo; Save, Save As and New; saving pasted Markdown; dirty indicators; Save/Discard/Cancel prompts; encoding and line-ending preservation; external-file conflict handling; exports that include the latest unsaved edit.

## Verified on the public Windows x64 build

- 36/36 unit and filesystem tests passed.
- 22/22 packaged viewer integration checks passed.
- 15/15 packaged editor integration checks passed.
- The actual portable executable launched, rendered math and Mermaid, edited Markdown and saved the result to disk.
- Save, Save As, failed writes, external changes, conflict copies, canceled navigation and close/save behavior were exercised against real temporary files.
- HTML exported through the UI and reopened independently; PDF export passed structural/multipage checks.
- Native bridge available; renderer Node access absent; sandbox and sanitization checks passed.
- Supplemental and Electron/Chromium license files present in the packaged payload.

[Sanitized machine-readable checks](v1.1.0-checks.json) are included in the source. GitHub-hosted CI status is shown separately on the repository; local checks do not imply that remote CI has run.

## Limits

Windows x64 only. Executables are unsigned. The installer was built but not installed into a normal Windows profile. Native dialog answers and clipboard writes are substituted during automated tests; actual renderer, IPC and filesystem behavior is exercised. PDF pages were structurally checked in this public rebuild, not visually re-reviewed. There is no autosave or crash-recovery store. Executable Markdown dialects, whole-vault transclusion and HTML-to-Markdown conversion are not included. File revision checks reduce ordinary overwrite conflicts but do not make Folio a transactional multiwriter editor.
