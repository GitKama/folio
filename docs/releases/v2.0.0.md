# Folio 2.0.0 verification

Folio 2.0 rebuilds the Windows desktop application with Rust/Tauri and the system WebView2 runtime. The bundled document interface and Markdown libraries remain JavaScript. Electron and its runtime are no longer distributed.

## Local acceptance

- 36 JavaScript regressions: Markdown dialects, sanitization, PDF transformations and Teams conversion.
- 7 Rust regressions: encodings, BOMs, mixed/CRLF line endings, safe writes, disk conflicts, size limits, invalid files, contained paths and export-title escaping.
- 13 native integration checks in the actual WebView2 application: CLI opening, source editing, math, Mermaid, Graphviz, local images, saves, external reload, conflict Cancel/Replace, native clipboard formats, self-contained HTML, all three PDF profiles, unsaved export content, New/Save As and layout captures.
- 6 production-runtime checks: embedded frontend startup, welcome diagrams, absent test commands, live editing, successful native Teams copy and no uncaught renderer errors.
- Rust Clippy with warnings denied; JavaScript dependency audit clean at release preparation.
- PDF page rendering and text extraction checked for all profiles. Native CF_HTML contains semantic HTML and CF_UNICODETEXT preserves Unicode fallback text.
- Light, dark, split and 760×560 compact document surfaces visually reviewed. Native controls, visible keyboard focus and reduced-motion styling are retained.

The native integration executable is compiled with test-harness to substitute dialog choices and inspect synthetic clipboard data. Filesystem writes, WebView2 rendering, clipboard writes and PDFs remain real. The distributed executable is separately built without that feature and checked again; its SHA-256 is recorded by the production test and enforced by release assembly.

## Distribution

Windows x64 portable executable and NSIS installer. WebView2 must be installed for the portable executable; the installer can obtain the Microsoft bootstrapper when absent. Builds are unsigned. No automatic update service, account or cloud document storage is included.

The release includes source, dependency notices, Graphviz/Expat/Viz.js corresponding sources, verification notes and SHA-256 checksums. GitHub Actions independently runs the source tests, native checks and production smoke on Windows; see the workflow status for the tagged commit.

## Boundaries

Windows 11 was tested locally. Windows 10 is a supported build target but was not separately exercised on a physical Windows 10 machine. WebView2 is maintained by Microsoft and can vary by machine. Tests do not prove every printer, display scale, filesystem or Markdown dialect.

The Teams converter retains the 1.3 behavior previously checked in an unsent Windows Teams desktop draft. The new Rust clipboard transport is verified against real Windows HTML and Unicode formats. No universal Teams-client fidelity, sent-message rendering or tenant-policy guarantee is made.

Recent documents migrate from the legacy profile when the new store is empty. Legacy files are not modified; reading preferences use the new profile and can be imported. There is no crash-recovery store or collaborative file locking.
