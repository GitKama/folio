# Folio 1.0.0 — the Markdown reader

Public release prepared on 21 September 2026 from the original reader application developed on 16 September 2026.

## Included

Read, Split and read-only Source views; five Markdown profiles; outline, search, themes, recent files and live reload; tables, tasks, callouts, footnotes, front matter, highlighted code, KaTeX, Mermaid and Graphviz; self-contained HTML and PDF exports.

The public build adds MIT metadata, supplemental upstream licenses, matching third-party source availability and project documentation. Application behavior is retained. This is a new public packaging build, so its hashes differ from the earlier private artifacts.

## Verified on the public Windows x64 build

- 30/30 unit and filesystem tests passed.
- 22/22 integration checks passed against the packaged application.
- Portable executable launched and rendered local Markdown, math and Mermaid.
- HTML exported through the real UI and reopened independently with images, diagrams and fonts.
- PDF exported through the UI and passed structural/multipage checks.
- Native bridge available; renderer Node access absent; sandbox and sanitization checks passed.
- Supplemental and Electron/Chromium license files present in the packaged payload.

[Sanitized machine-readable checks](v1.0.0-checks.json) are included in the source. GitHub-hosted CI status is shown separately on the repository; local checks do not imply that remote CI has run.

## Limits

Windows x64 only. Executables are unsigned. The installer was built but not installed into a normal Windows profile. Native dialog answers and clipboard writes are substituted during automated tests; actual renderer, IPC and filesystem behavior is exercised. PDF pages were structurally checked in this public rebuild, not visually re-reviewed. Source is read-only in 1.0. Executable Markdown dialects, whole-vault transclusion and HTML-to-Markdown conversion are not included.

The release includes portable and installer EXEs, exact tagged source, corresponding third-party sources, license notices and SHA256SUMS.txt. See the repository user guide for installation and usage.
