# Contributing

Small, focused changes are welcome.

1. Open an issue for substantial behavior changes.
2. Fork and create a branch from main.
3. Follow [development setup](docs/development.md).
4. Add focused regression coverage when behavior changes.
5. Run unit, build and relevant desktop checks.
6. Submit a pull request explaining the problem, changed behavior, validation and remaining limits.

Use synthetic examples. Do not include personal documents, private paths, credentials, internal hostnames, generated builds, node_modules, profiles or logs.

Keep dialect choices explicit and preserve sandboxing, sanitization and local path boundaries. Avoid unrelated dependency upgrades. Update notices when dependencies change.

Contributions to original Folio code are submitted under MIT. Submit only material you have the right to contribute and preserve upstream licenses. Be respectful and keep discussion focused on the software.
